# Assets Required

Please add the following assets to make the game work:

## Images
- `images/mouse.png`: A PNG image of a mouse character (recommended size: 40x40 pixels)

## Sounds
- `sounds/background.mp3`: Background music for the game

Note: Make sure to place these files in their respective directories:
- Images go in the `images/` directory
- Sound files go in the `sounds/` directory
